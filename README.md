# 和平紙鶴大冒險

給 9 歲孩子的廣島二戰歷史互動學習網頁，搭配 5 天 4 夜的親子旅行（2 大 1 小，4 月中旬）使用。

## 玩法

- **地圖**：廣島城、縮景園、和平紀念公園、原爆圓頂館、宮島、吳市、鐵鯨館、台灣基地共 8 個地點。
- **問答**：第一次答對得 3 隻紙鶴，第二次 2 隻，之後 1 隻；答對後顯示講解與「台灣連結」。
- **自由探索**：所有地點一開始就開放，行程順序改變時可以直接玩任何一關；地圖虛線只是建議路線。
- **鶴寶**：每完成一個地點得到一隻鶴寶夥伴，每隻在答題時可刪掉一個錯誤選項。
- **現場任務**、**和爸媽聊聊**：旅途中完成可再得紙鶴。
- **時光機**：把 1894～1945 年的事件排成時間軸。
- **爸媽手冊**：每日行程、交通、歷史講解、訂房訂機票指南、行前清單。

進度只存在該裝置的瀏覽器（localStorage），不會上傳。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 頁面骨架、頂部列、底部導覽 |
| `data.js` | 所有內容：地點、問答、歷史講解、台灣連結、行程、交通、指南 |
| `app.js` | 遊戲邏輯與畫面（hash 路由） |
| `style.css` | 樣式 |

要修改題目或行程內容，只需編輯 `data.js`。

分享預覽圖 `og-image.png`（1200×630）的原稿是 `og/og.html`，修改後用 Edge 無頭模式截圖重新產生。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。

## 注意

傷亡人數、少年工人數等為常見概略數字；交通時間與價格為估計值。出發前請以各展館、交通公司官網為準。
